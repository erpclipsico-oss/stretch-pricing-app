Users

"Price adjustment" is added straight onto the quoted $/KG unit price for every quote that user builds — e.g. set 0.03 for a foreign-seller account that should quote 3¢/KG above the normal costing/factors. Leave at 0 for local sellers using standard pricing. "Hidden markup" is a SEPARATE, silent markup on top of that — Stretch Film and Strap each have their OWN markup, independently in either Percent (multiplicative) or Cents/KG (a flat $/KG add-on) mode (e.g. +3¢/KG on Stretch but +5% on Strap for the same user, at the same time). Never shown to the user anywhere in the app (screen, PDF or Excel).
